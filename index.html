Cara Penggunaan Sistem Pendataan Nilai

1. Identitas & Matkul

Masukkan NIM, Nama Lengkap mahasiswa, serta pilih mata kuliah Teknik Mesin (misal: Termodinamika, Elemen Mesin, Mekanika Fluida).

2. Input Komponen Nilai

Isi nilai rentang 0–100 untuk komponen Tugas (20%), Praktikum (20%), UTS (30%), dan UAS (30%).

3. Konversi Otomatis

Klik Hitung & Simpan. Sistem otomatis menghitung Nilai Akhir, Huruf Mutu (A s.d. E), dan Bobot SKS sesuai aturan SIAKAD UNJ.

4. Ekspor Laporan

Data otomatis tersimpan di browser. Klik Unduh Rekap CSV untuk mengunduh file Excel/SIAKAD.
